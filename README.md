# HTML & CSS Cheat Sheet Web App

An interactive and beginner-friendly reference tool for learning HTML and CSS. This web application provides code examples, live previews, and useful playgrounds to help users understand essential web development concepts.

## Project Overview

The HTML & CSS Cheat Sheet Web App is designed to make learning front-end web development easier through interactive examples and practical coding references.

Users can explore HTML elements, CSS properties, experiment with code, and see how changes affect a webpage in real time.

## Features

- **HTML Reference:** Explore common HTML tags, elements, and structures.
- **CSS Reference:** Learn CSS properties, selectors, layouts, and styling techniques.
- **Search Functionality:** Quickly find specific HTML and CSS topics.
- **Category Filters:** Browse HTML, CSS, or all available references.
- **Live Code Playground:** Edit HTML and CSS and see the results instantly.
- **Copy Code:** Copy individual code examples or complete pages.
- **Flexbox Playground:** Experiment with Flexbox layouts.
- **CSS Grid Playground:** Practice creating grid layouts.
- **Color Helper:** Experiment with colors and CSS color values.
- **Quick Quiz:** Test your understanding of HTML and CSS.
- **Saved Examples:** Keep track of favorite code references.
- **Dark and Light Themes:** Switch between different viewing preferences.
- **Responsive Design:** Access the application on different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Getting Started

No installation or additional software is required.

1. Clone or download this repository.
2. Open the project folder.
3. Locate `index.html`.
4. Open the file using your preferred web browser.
5. Start exploring the HTML and CSS references!
